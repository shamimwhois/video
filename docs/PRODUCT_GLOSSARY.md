# Product Glossary

- **Project:** User-owned editing container and revision history.
- **Sequence:** Timeline composition with frame rate, dimensions, tracks, and duration.
- **Asset:** Immutable imported/generated source media or derivative.
- **Clip:** A time-bounded use of an asset or generated visual element on a sequence.
- **Track:** Ordered lane that contains clips and defines compositing/audio behavior.
- **Playhead:** Current sequence time shown in preview.
- **Source range:** In/out interval selected from an original asset.
- **Timeline range:** Position and duration of a clip in a sequence.
- **Proxy:** Lower-cost derivative used to improve editing responsiveness.
- **Render:** Background process that produces a deliverable from an immutable sequence revision.
- **Render profile:** Validated output dimensions, frame rate, codec, bitrate/quality, and audio settings.
- **Edit plan:** AI-generated typed proposal; not applied until approved.
- **Operation:** Atomic validated change to project/sequence state.
- **Revision:** Immutable committed snapshot of project state.
- **Preview/export parity:** Degree to which browser preview matches final rendered output.
